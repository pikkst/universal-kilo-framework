# Feature Checklist

## Scope

- [ ] Feature matches the requested task.
- [ ] Existing implementation was checked first.
- [ ] No unrelated refactor is included.
- [ ] Owner module is clear.

## User Value

- [ ] Feature provides clear user or business value.
- [ ] User flow is reachable from the real app.
- [ ] UI action reaches the intended logic.
- [ ] Inputs are validated in code.

## Architecture

- [ ] Existing patterns are reused.
- [ ] Duplicate systems are avoided.
- [ ] Persistence impact is identified.

## Validation

- [ ] Tests were added or updated when needed.
- [ ] Validation commands were run or reported.
- [ ] Documentation impact is handled.
