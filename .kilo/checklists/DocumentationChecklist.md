# Documentation Checklist

## Accuracy

- [ ] Documentation matches actual project state.
- [ ] Planned work is not described as complete.
- [ ] Known limitations are stated.

## Scope

- [ ] Only relevant docs are changed.
- [ ] No unrelated rewrite is included.
- [ ] Links or references are updated when needed.

## Reports

- [ ] Implementation report explains findings, changes, files touched, validation, and remaining notes.
