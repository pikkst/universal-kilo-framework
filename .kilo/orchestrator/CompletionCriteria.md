# Completion Criteria

## Complete Means

A task is complete only when:

- requested scope is implemented
- unrelated work is not included
- relevant validation was run or honestly reported
- tests were added or updated when needed
- documentation impact is handled
- known limitations are listed
- visible Guardian Pass is produced

## Validation Defaults

Use the project profile to choose commands.

Common commands:

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

If a command is unavailable, state that clearly.

## Rule

Do not call work complete only because files changed.

Completion requires the requested outcome and review readiness.
