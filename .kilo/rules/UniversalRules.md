# Universal Rules

## Scope

- Work on the requested task only.
- Keep unrelated improvements as follow-up notes.
- Reuse existing systems before adding new ones.
- Preserve project-specific architecture rules from `project_profile/PROJECT_PROFILE.md`.

## Context

- Start from `.kilo/README.md` and `.kilo/SYSTEM_MAP.md`.
- Use the Context Engine before planning.
- Load the smallest useful context.

## Code

- Prefer clear, typed, maintainable code.
- Avoid weakening public types.
- Keep business logic out of UI when a core/service layer exists.
- Add tests for meaningful behavior.

## Delivery

- Report validation honestly.
- Document files touched and remaining notes.
- Produce a visible Quality Gate summary.
