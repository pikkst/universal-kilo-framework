# Context Stop Rules

## Stop Loading When

The agent can answer:

- What is the task?
- Which system owns the change?
- Which files are likely to change?
- What is in scope?
- What is out of scope?
- Which validation is required?
- Which docs are required?

## Hard Stop

Stop reading more files when additional context would only add background knowledge and not change the plan.

## Rule

More context should reduce risk, not increase confidence only.
