# Web App Profile

Use this profile for React, Vue, Angular, Svelte, Next.js, Nuxt, Remix, Astro, and similar applications.

## Common Context

Read:

- routing files
- state management files
- main UI component
- related feature component
- API client if the feature calls backend
- tests near the feature

## Common Validation

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

## Review Focus

- UI is reachable from the real app flow
- form inputs are validated in code
- loading and error states exist when needed
- accessibility basics are considered
- API types are not weakened
