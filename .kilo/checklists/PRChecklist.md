# Pull Request Checklist

## Scope

- [ ] One task equals one branch and one PR.
- [ ] PR title is clear.
- [ ] Summary explains what changed.
- [ ] Out-of-scope work is not included.

## Validation

- [ ] Validation commands were run or not-run reason is stated.
- [ ] Tests pass or failures are clearly documented.
- [ ] Build status is reported when applicable.

## Guardian Pass

- [ ] Guardian Pass is visible in agent log, task report, or PR notes.
- [ ] Architecture was checked.
- [ ] User flow was checked when relevant.
- [ ] API quality was checked when relevant.
- [ ] Persistence impact was checked when relevant.
- [ ] Merge readiness was checked.
