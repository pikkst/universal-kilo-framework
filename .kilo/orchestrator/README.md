# Orchestrator

The Orchestrator controls task execution after the Context Engine has classified the task.

## Use Order

1. `TaskLifecycle.md`
2. `ExecutionPlan.md`
3. `ReviewPipeline.md`
4. `CompletionCriteria.md`

## Rule

The Orchestrator should reduce confusion, not add ceremony.

Use the smallest workflow that safely completes the task.
