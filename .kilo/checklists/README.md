# Checklists

Use the smallest checklist set that matches the task.

## Index

- `FeatureChecklist.md` - new user-facing or system features
- `BugfixChecklist.md` - fixes and regressions
- `APIQualityChecklist.md` - public types, helpers, and module APIs
- `TestingChecklist.md` - tests and validation
- `DocumentationChecklist.md` - docs quality
- `PRChecklist.md` - PR readiness

## Rule

Checklist answers must be truthful and based on the actual work.
