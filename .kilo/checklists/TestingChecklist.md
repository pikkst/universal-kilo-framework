# Testing Checklist

## Fit

- [ ] Tests cover meaningful behavior.
- [ ] Tests match the owning system.
- [ ] Regression tests are added for bug fixes when practical.

## Determinism

- [ ] Seeded or generated systems use deterministic inputs in tests.
- [ ] Timing-sensitive tests use controlled time when possible.

## Quality

- [ ] Test names describe the assertion.
- [ ] Assertions are not weakened only to pass.
- [ ] Known gaps are documented.
